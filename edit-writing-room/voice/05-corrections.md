# 05 교정 이력

> `v1.6.0` · 갱신 2026-08-01 · 출처: hong-voice-reference v1.6.0 내장 사본(2026-09-23). edit-writing-room 편집 기준으로 쓴다.

> 홍작가가 실제로 고친 표현만 쌓는다. 규칙보다 이 기록이 정확하다.
> 같은 표현을 두 번 이상 고쳤을 때 읽는다. 매 작업마다 읽지 않는다.

---

## 이 문서의 역할

`01-voice.md`가 규칙을, `02-glossary.md`가 단어를, `03-anti-traces.md`가 제거 대상을 정한다면, 이 문서는 **규칙이 아직 잡아내지 못한 것**을 담는다.

같은 표현을 두 번 이상 고쳤다면 규칙에 구멍이 있다는 뜻이다. 여기 기록하고, 세 번째 반복되면 해당 층 문서로 승격한다.

---

## 기록 규칙

- 홍작가가 **직접 고친 것만** 기록한다. AI가 스스로 판단해 바꾼 것은 기록하지 않는다
- 최신 항목을 위에 쌓는다
- 같은 표현이 3회 이상 반복되면 `승격` 열에 대상 파일을 적고, 다음 갱신 때 해당 파일로 옮긴다
- 승격이 끝난 항목은 이 표에서 지우지 않고 `승격 완료`로 표시한다. 판단 근거가 남아야 한다

## 기록 경로 (누가·언제·어떻게)

글 작업 중에는 **이 파일을 고치지 않는다.** 스킬 파일은 세션이 끝나면 초기화되므로 실행 중 편집이 남지 않고, 작업 도중 기준을 바꾸면 같은 글 안에서 기준이 두 개가 된다.

| 시점 | 주체 | 하는 일 |
|---|---|---|
| 글 작업 말미 | 실행 중인 스킬 | 홍작가가 표현을 고쳤으면 **교정 카드 한 줄**만 대화창에 출력 |
| 별도 갱신 세션 | 홍작가 요청 | 모은 카드를 아래 표에 추가 → 3회 도달분 승격 → 재패키징 |

교정 카드 형식은 아래 한 줄이다. 이 형식으로 나와야 나중에 표로 옮기기 쉽다.

```text
[교정] 수정 전 → 수정 후 | 이유 | 채널
```

카드가 나왔는데 갱신 세션을 열지 않으면 이력이 쌓이지 않는다. 카드 3~5장이 모이면 갱신을 한 번 돌린다.

## 승격 절차

1. 대화에서 모은 교정 카드를 위 표에 추가하고 `반복` 열을 갱신한다
2. `반복`이 3에 도달한 항목의 승격 대상 파일(`01`·`02`·`03`)에 조항이나 사례를 추가한다
3. 이 문서 표의 `승격` 열에 `승격 완료`와 대상 파일명을 적는다
4. `references/` 각 파일 머리의 `갱신` 날짜와 SKILL.md의 `version`을 올린다
5. 추가한 항목이 01~04 파일의 기존 규칙과 충돌하지 않는지 대조한다
6. `.skill`을 다시 패키징하고 설치한다

승격은 갱신 작업에서만 한다. 글 쓰는 도중에 층 문서를 고치지 않는다.
