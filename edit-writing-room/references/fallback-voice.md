# 폴백 문체 기준 (정본 호출 실패 시)

`voice/` 파일을 열지 못해 3층(`01-voice.md`·`02-glossary.md`·`03-anti-traces.md`)을 확보하지 못했을 때만 이 문서를 기준으로 편집한다. 한 층이라도 읽히면 그쪽이 우선이고 이 문서는 쓰지 않는다.

폴백 모드로 실행한 산출물에는 실행 모드를 표기한다.

---

## A. 보이스 최소 기준

| # | 항목 | 기준 |
|---|---|---|
| 1 | 한 문장 정의 | 현상을 관찰해 문제를 재정의하고, 해결이 아니라 판단 기준의 이동으로 독자의 사고를 정렬하는 설명 중심 글쓰기 |
| 2 | 어조 | 가르치지 않되 이끈다. 독자 위에 서지 않고 같은 문제를 함께 본다. 설득보다 납득 |
| 3 | 시점 | 확인된 경험만 1인칭으로 쓴다. 원고에 장면이 없으면 1인칭 장면을 만들지 않고 관찰·자료·개념에서 시작한다 |
| 4 | 전개 | 경험형은 `실행·장면 → 기대 또는 막힘 → 실제 어긋남 → 현재 판단`. 개념형은 `문제 상황 → 개념 → 판단 기준 → 실제 적용` |
| 5 | 리듬 | 짧은 관찰 → 긴 설명 → 짧은 판단. 같은 길이·같은 역할 문장이 3개 이상 이어지면 점검한다. 문단 길이를 균일하게 맞추지 않는다 |
| 6 | 어휘 | 기능·도구·기술보다 기준·역할·구조·설계·판단 같은 사고 중심 명사. 추상어는 반드시 구체 장면과 붙인다 |
| 7 | 소제목 | 기능명 금지. 행동·판단 중심 문장으로 쓴다 |
| 8 | 마무리 | 현재 판단·달라진 행동·현재 작업 상태·남은 질문 중 하나로 닫는다. 요약·행동 촉구·의미 부여를 덧붙이지 않는다 |

### 종결어미

`~합니다`체가 기본이며 채널 규칙이 있으면 그쪽을 따른다. 한 글 안에서 중심 종결을 유지한다. 복합 종결은 단순화한다(`바뀌어 있었습니다` → `바뀌었습니다`). 공개 원고의 판단문을 볼드로 자동 강조하지 않는다.

### 이탈 징후

1. 방법·팁·요령이 기준 설명 없이 먼저 나온다
2. 감정적 공감·동기 부여 문장이 논리 설명보다 앞선다
3. 읽고 난 뒤 장면과 근거는 없고 추상적 기준·구조·관점만 남는다

## B. AI 흔적 제거 최소 기준

### 제거 대상

| 유형 | 표현 |
|---|---|
| 과장형 형용사 | 혁신적인, 획기적인, 창의적인, 강력한, 완벽한, 최고의, 탁월한, 뛰어난, 놀라운, 압도적인 |
| 모호한 부사 | 매우, 굉장히, 상당히, 꽤, 쉽게, 빠르게, 간편하게, 효율적으로, 효과적으로, 다양하게 |
| 빈 완곡 | ~할 수 있습니다, ~라고 볼 수 있습니다, ~하는 데 도움이 됩니다, 어느 정도, 부분적으로, 다소 |
| 역할 없는 연결어 | 전반적으로 볼 때, 이러한 측면에서, 결과적으로, 뿐만 아니라, 더 나아가, 이를 통해 |
| 챗봇 말투 | 좋은 질문입니다, 물론입니다, 아래와 같이 정리해드리겠습니다, 지금부터 살펴보겠습니다, 결론부터 말씀드리면 |
| 상투 마무리 | 주목할 만합니다, 의미가 큽니다, 새로운 가능성을 보여줍니다, 중요한 시사점을 제공합니다, 새로운 장을 엽니다 |

지운 자리는 비워두지 않는다. 조건·수치·비교 기준·구체 사례·실제 행동·판단 문장 중 하나로 교체한다.

### 보존 조건

다음은 출현만으로 제거하지 않는다.

- 사용자가 직접 쓴 문장에 있고 당시 체감을 나타낼 때
- `빠르게`·`쉽게`가 실제 전후 비교나 작업 조건을 설명할 때
- 가능 조건·허용 범위·전제가 분명한 `~할 수 있습니다`
- 직접 인용, 코드, 파일명, 규칙 설명용 예문
- 실제 불확실성과 유보된 태도

### 구조 점검 (반복 밀도 기준)

한 번의 출현이 아니라 문서 전체의 반복을 본다.

- `A가 아니라 B다`, `단순히 A를 넘어 B다`가 여러 문단의 결론을 대신하면 한두 번만 남긴다
- `X: Y` 형태 콜론 소제목이 칼럼·에세이에서 반복되면 단일 소제목으로 줄인다
- 문두 접속사(또한·따라서·즉)가 여러 문단의 같은 자리에서 시작하면 줄인다
- 연결어미 뒤 쉼표 반복(`진행하고,`·`확인하면서,`)은 쉼표를 빼거나 문장을 나눈다
- 모든 문단이 같은 문장 수·같은 종결로 이어지면 각 문단의 재료에 따라 경계를 다시 본다

### 조합 금지

`모호한 부사 + 과장형 형용사 + 가능성 표현 + 추상 명사`가 한 문장에 함께 나오면 AI 흔적으로 본다.

## C. 과윤문 역점검

수정 후 아래를 확인한다. 하나라도 걸리면 해당 구간을 원문으로 되돌린다.

- 실제 불확실성을 확정된 사실로 바꾸지 않았는가
- 사용자가 직접 쓴 체감 부사와 전환어를 기계적으로 지우지 않았는가
- 문장 길이·문단 모양을 일정하게 만들지 않았는가
- 모든 문단 끝에 판단문을 붙이지 않았는가
- 원문에 없던 상투구·비유·분석어·수치를 넣지 않았는가
- 수치·날짜·고유명사·직접 인용의 내용과 위치를 보존했는가
- 평균적인 한국어에는 가까워졌지만 저자의 어휘와 판단 강도는 약해지지 않았는가

변경률이 원문의 30%를 넘으면 사실·주장·수치·인용과 문체 소유감을 다시 대조한다. 50%를 넘으면 수정 근거가 확인된 구간만 남기고 나머지를 원문으로 되돌린다. 이 수치를 맞추려고 수정량을 늘리거나 줄이지 않는다.

## D. 폴백 모드의 한계

이 문서로 대체되지 않는 것이 둘 있다. 산출물에 함께 알린다.

| 정본 | 대체 여부 | 결과 |
|---|---|---|
| `01-voice.md` | 축약 대체 (A절) | 문체 방향은 잡히나 세부 예시 판단은 약해진다 |
| `03-anti-traces.md` | 축약 대체 (B·C절) | 주요 금지어는 걸러지나 승인 예외 판단·흔적 지수 계량은 약해진다 |
| `02-glossary.md` | 대체 불가 | 단어 단위 선택·회피 목록을 쓸 수 없다. 애매한 표현은 고치지 않고 원문을 유지한다 |
| `04-examples.md` | 대체 불가 | 승인 문단과 대조할 수 없다. 사용자가 직접 쓴 것으로 보이는 표현은 판단을 보류하고 남긴다 |

두 정본을 못 쓰는 상태이므로 폴백 모드에서는 판단이 애매한 문장을 고치지 않는 쪽을 택한다. **사용자가 편집 강도를 명시했으면 그 값을 그대로 지킨다.** 사용자 지시가 최소 카드보다 우선한다. 강도 지정이 없을 때만 `표준`을 기본으로 둔다.
