# 3인 편집실 (edit-writing-room)

완성 원고를 작가·독자·편집자 세 자리로 나눠 검토하고 다듬는 Claude 스킬(Skill)입니다.

## 트리거

3인 편집실, 편집실로 봐줘, 멀티 에이전트 퇴고, 독자 검토 후 편집, 타깃 독자에게 먼저 읽혀줘, 독자 리포트

## 소개

AI에게 퇴고를 맡기면 한 에이전트가 쓰고, 읽고, 잘 썼다고 판단까지 합니다. 이 스킬은 그 자리를 작가·독자·편집자 셋으로 나눕니다. 관점, 경험 공개 범위, 발행 여부는 작가(사용자)가 정합니다. 독자 역할은 40~50대 AI 입문자 시선으로 원고를 읽고 막히는 곳만 보고하며, 문장은 고치지 않습니다. 편집자 역할은 독자 리포트를 받아 스킬에 내장된 문체 기준(`voice/`)으로 수정하되, 원고에 없는 사실과 경험은 추가하지 않습니다. 다른 스킬을 호출하지 않고 이 스킬 하나로 동작합니다.

기본 결과는 수정본이 아니라 제안입니다. 중심 판단 한 문장, 독자가 막힌 곳(3개 이내), 우선 수정 3가지(현재 문장, 수정 방향, 이유), 보존할 부분, 총평이 돌아옵니다.

> 문체 기준은 홍작가(HONGS LAB)의 글쓰기 규칙과 승인 원문으로 만들었습니다. 편집자 역할은 이 문체에 맞춰 고칩니다. 다른 문체를 쓰려면 `voice/` 폴더의 파일을 자신의 기준으로 바꿔 넣습니다.

## 쓰는 곳

칼럼, 페이스북·블로그·브런치 글, 에세이, 책 한 챕터처럼 완성된 원고 한 편. 맞춤법 몇 곳은 강도를 최소로, 문체만 바꿀 때는 편집자 역할만 불러 씁니다.

## 호출 예시

```text
이 원고를 3인 편집실로 검토해줘.
이 글을 독자 역할로만 읽혀줘. 어디서 막히는지 알려줘.
독자 검토 없이 편집자 역할로만 다듬어줘.
1번과 3번만 반영해줘.
제안 전부 반영해서 수정본 줘.
```

## 호출 축

| 축 | 값 | 기본값 |
|---|---|---|
| 역할 | 독자 · 편집자 · 편집실 · 병렬 | 편집실 |
| 출력 | 제안 · 선택반영 · 전체반영 | 제안 |
| 강도 | 최소 · 표준 · 구조 | 표준 |

## 설치

- Claude 앱(claude.ai·데스크톱): Releases의 `edit-writing-room.skill` 파일을 내려받아 스킬 설정에서 업로드합니다.
- Claude Code: `edit-writing-room/` 폴더를 `~/.claude/skills/`에 복사합니다.

독자·편집자 역할은 서브에이전트로 실행되므로, 서브에이전트를 지원하는 환경(Claude Code, Cowork)에서 전체 흐름이 동작합니다.

## 폴더 구조

```text
edit-writing-room/
├── SKILL.md          실행 흐름(STEP 0~5)·호출 축·점검표
├── references/       역할 브리프: reader-brief, editor-brief, fallback-voice
└── voice/            문체 기준: 01-voice, 02-glossary, 03-anti-traces, 04-examples, 05-corrections
```
